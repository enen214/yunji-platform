## 获取本轮接收分支

私有仓库成员在空目录执行：

```powershell
git clone --branch feature/client-prototype-rebuild-20261021 --single-branch https://github.com/qianyue303jiaojie/yunji-platform.git
Set-Location yunji-platform
git rev-parse HEAD
```

已有仓库先保存自己的改动，再执行 `git fetch origin`、`git switch feature/client-prototype-rebuild-20261021`、`git pull --ff-only origin feature/client-prototype-rebuild-20261021`。记录实际提交 SHA；不要从旧分支取本轮功能，不自动合并 main。

## 本地启动速查

当前本地运行器仅验证过 Windows。需要 Python 3.10+、JDK 21、Maven 3.9、MySQL 8 服务端与客户端、Redis、Node.js/npm。完整安装与工具路径见 [本地说明](docs/本地开发与验收使用说明.md)。在仓库根目录执行：

```powershell
python -m pip install -r scripts/requirements.txt
Set-Location apps/admin
npm ci
Set-Location ../client
npm ci
Set-Location ../../tests
npm ci
npx playwright install chromium
Set-Location ..
python scripts/build_acceptance.py
python scripts/workbench.py start
```

另一终端在仓库根目录执行：

```powershell
python scripts/workbench.py code alice
python scripts/workbench.py authorize alice --quota 5
python scripts/workbench.py status
# 人工验证完成后
python scripts/workbench.py stop
```

- C 端 H5：`http://127.0.0.1:5173/#/`
- 管理端：`http://127.0.0.1:5174/#/login`
- API：`http://127.0.0.1:18088`

隔离夹具管理员 `admin/admin123`、创作者 `test1/666666`、审核员 `test/666666` 仅用于此本地环境。C 端在开发登录页使用 `local-client` 和短时单次合成码。每次启动创建新库，不延续上次手工数据；不会接管已占用的 33308/16379/18088/5173/5174 端口。生产配置不能使用夹具或本地网关。

## 服务器交接

在受控构建机使用 `python scripts/delivery_bundle.py --destination <工程外目录>` 生成研发接收包。Git 仓库不包含运行依赖缓存，拉取源码后需要安装依赖和构建。交付包包含源码、部署模板、迁移、文档、报告和构建产物；生成时须重新核对 manifest 和源码指纹，旧 ZIP 不自动随 Git 更新。

生产配置入口是 [deploy/api.env.example](deploy/api.env.example) 和部署手册第 5 节。数据库迁移到 V22，只增不改；首次 `bootstrap` 替换管理员密码并停用框架初始账号，不在每次升级重跑。身份 HMAC、加密密钥和 token secret 应稳定保管。

无微信资源的服务器只能验后台、公开 H5 和基础运维；生产 H5 当前没有独立客户登录方案，客户写操作和真实通知仍需平台联调。不得使用 `LOCAL_FAKE` 或合成登录代替正式平台能力。
