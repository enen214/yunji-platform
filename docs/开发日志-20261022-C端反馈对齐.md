## 验收基准

1. C 端仅普通信息/通知/攻略三种类型，兼容历史后台枚举；搜索板块多选 OR，与标签/关键词取 AND，标签随所选板块联动。不展示学校组织。
2. 三种详情分别呈现通知有效期与真实倒计时、攻略适用说明/步骤/注意事项、普通信息联系方式/相关资讯；删除解读说明和详情已读按钮，信息盒子保留显式版本已读。
3. 板块→标签→关键词浏览链路完整，移除详情关注板块/标签入口；推送标签仍由信息盒子专门管理。
4. 独立活动专题和关联资讯排序，由管理端维护、轮播链接进入，不能借板块或报名活动冒充专题。
5. 资讯和关联关键词关注状态持久化，可原地切换；关键词弹窗只列本条资讯关键词。
6. 详情强提醒确认后，后端原子创建/恢复日常规则及资讯关注，重复操作幂等。已有即时模式不静默降级。取消提醒保留关注，取消关注同时停用对应变更型提醒并明确提示。
7. 强提醒日常视图突出待处理更新，并显示已开启的跟踪；即时展示真实授权；关键词基于关注及新增资讯。添加跟踪不伪造更新/送达。
8. 关注管理按板块→标签→关键词折叠，资讯关注独立 Tab；多归属用真实关系，无关系进入未归类。不显示“选择板块与标签”。
9. 信息盒子按原型三视图，条目展示类型/时间/摘要展开，左滑揭示已读确认；版本冲突不冒充成功。
10. 资料页删除学校组织及注销入口，保留昵称/脱敏手机号与退出。沿用另一会话的新微信登录。
