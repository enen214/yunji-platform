## 当前工程参考

- 已有 Linux 原生运行模板，基线为 JDK 21、MySQL 8、Redis 7、Nginx；数据库工具需要 Python 3.10+。
- 运行已构建的 JAR 和前端静态文件无需服务器安装 Maven 或 Node.js。
- 已新增 `deploy/docker` 的 amd64 Dockerfile/Compose，沿用现有后端变量；本机没有 Docker，待目标环境实际构建和启动验收。
- 默认 H5 路径为 `/`，管理端为 `/admin/`，API 监听 18088；目标环境有路径或端口限制时需提前告知。
- 当前附件使用私有本地目录；仅提供 OSS/S3 时，需要另外适配。
- CPU/内存/磁盘请报本项目实际可用量，已有“4 核/8GB/100GB”选型参考不作为经过压测的最低配置。
