# 产品基线二次开发教程

## 先读和变更纪律

先读 [开发与交接](产品基线重制开发与交接-20261027.md)、[决策表](decisions/产品基线工程决策-20261027.md)、`contracts/openapi.yaml`、迁移快照说明。改动前检查 `git status` 并保留他人未提交内容。开发业务时只编辑 `yunji-content` 与对应客户端；基座 auth/system/monitor 是授权框架边界，除非有已验证缺陷不重做。`yangben` 不作为 import/source/dependency，不复制其页面、SQL、endpoint 或部署文件。

## 新增业务能力

1. 先在 `docs/decisions` 记录触发规则、取舍、权限、状态机、失败恢复和外部依赖。
2. 有持久化变化只追加 `database/migrations/V27__...sql`。迁移单向、校验和固定，不修改已发布V1–V26；测试需从干净 schema 连续迁移并重复识别。
3. 在领域内分清 API DTO、命令、查询、数据访问和权限。所有用户输入绑定参数，事务放在应用命令边界，跨主体访问做负例，状态变化使用锁版本/幂等键。
4. 同步 OpenAPI、前后端类型、管理页面/C端展示、演示夹具和数据最小化。不要让前端自己拼权限或个人盒子去重。
5. 添加可失败的行为验收：正确主体/错误主体、正常/边界、并发/重试/中断、撤回后旧链接。浏览器回归覆盖真实控件和导航。
6. 文档记录迁移、兼容窗口、开关默认、上线观察、回滚方案及外部未验事项；构建并刷新所有证据指纹。

## 关键扩展约定

- 资讯类型：由 content type dictionary 描述字段/renderer，新增 renderer 时同步后台编辑器、C端详情、安全净化、导入映射和微信产物验证。
- 排序：准入过滤、特殊优先级、普通分数、稳定ID顺序分层维护。需给 FeedSql 加固定时钟/数据库等价用例，禁止用无穷大权重模拟置顶。
- 强提醒：状态账本和 provider 结果分开。只有供应方明确拒收可安全重试；超时未知状态先查证，不盲目重发。提供者未真实接线时保持 fail-closed。用户界面永不泄露个人投递失败明细。
- 文件：全局文件版本不可原位覆盖；活动引用指定版本策略。外发 URL 必须短期、受信域名校验、不能返回 fileID。确认云上传与本地落盘一致性后才可扩大生产入口。
- 导入：只扩展显式 JSON 字段并同步示例/映射/字段校验；每行新事务，长批次须可续做。不可增加隐式标题更新或弱化上限。
- 菜单与账号：菜单可数据库配置但服务端 STAFF 检查必须保留；C端用户 token 永不进入管理员请求。

## 本地闭环

```powershell
python scripts/workbench.py start
python scripts/workbench.py code alice
```

按操作手册验证 C 端，再按管理员页面执行新增资讯、类型/分类、候选、更替、导入、文件、活动、评审、用户统计和提醒健康检查。工作台服务 Ctrl+C 停止，不要连接真实生产库。修改后：

```powershell
$env:YUNJI_TEST_MAVEN_SETTINGS=(Join-Path (Get-Location) '.runtime/maven-central.xml')
$env:PYTHONIOENCODING='utf-8'
python scripts/product_candidate_acceptance.py
python scripts/product_release_gate.py
```

若变更 `scripts`，会改变本轮所有脚本/测试指纹，完整回归需重新运行。报告只接受其sourceFingerprints与当前源码相同、sourceUnchanged为真且全部用例通过；旧日期旧报告不是当前证据。

## 数据与版本

用户数据默认不从 demo 迁入。需要样例从 `workbench_demo.py` 生成，只落隔离随机库。客户将来只提供数据时，先做脱敏导出、字段映射、重复/孤儿/唯一约束核对和新库试迁；生产迁移须独立授权与回滚演练。私有附件必须跟库一起备份，当前备份命令要求服务停止。

## 常见错误

- 只隐藏导航但不退役接口，或删掉仍被基座外键使用的数据表。
- 直接编辑已应用迁移、把“错误未知”提醒自动重试、把下载签发记成下载完成。
- 用本地成功短信/账号/资源声明真实微信能力通过；把 `YUNJI_LOCAL_SECRET` 配进生产。
- 因为 UI 能点就说功能完成；每个结论都要绑定实际业务行为和负例。
- 看到“release gate”或 `pushCandidateReady` 就跳过安全扫描、Linux Docker、接收团队验证。
