# 演示数据与本地人工验收

## 默认体验

执行 `python scripts/workbench.py start`，默认在本次新建的隔离测试库中，通过新工程真实API创建并审核发布6篇合成资讯、3个独立专题、3张轮播和5条推荐。轮播使用仓库自有PNG，不依赖外链图库或旧demo素材。标题均有“【验收演示】”，不代表真实学校安排。

C端：`http://127.0.0.1:5173/#/`；管理端：`http://127.0.0.1:5174/#/login`。可以在后台编辑、审核、下线或新增测试内容。普通信息有联系方式和相关资讯，攻略有步骤/注意事项，通知有当前有效或即将生效的时间示例；后者在未生效前不进入专题中的当前有效资讯。

登录使用 `python scripts/workbench.py code alice` 获取本地单次合成码。这些示例不自动关注、不伪造订阅授权，也不会创建已发送消息。测试提醒需先在界面明确开启，再按专项说明配置模拟额度。

## 隔离与重建

- 默认演示只由 `workbench.py start` 调用 `workbench_demo.py`，正式 `database_ops.py initialize/migrate` 和所有V1～V23迁移不插入演示业务数据。
- 测试创建走后台权限、不可变版本、审核发布与审计，客户端没有硬编码资讯列表。复制静态产物到空后端库时仍会空，正式内容由运营发布。
- 停止工作台再启动会新建隔离库，示例时间随当前时间生成；不把运行目录、登录码或工作台密钥交给生产。
- 空态测试使用 `python scripts/workbench.py start --no-demo-data`。
- 已运行的空工作台可执行 `python scripts/workbench_demo.py` 补一次演示。成功后同一工作台再执行会复用清单，不重复插入或覆盖人工改动；恢复全新演示请停止并重启。
- 导入入口只接受工作台状态指向的回环API，并先用本地密钥验证受保护合成登录端点。生产配置关闭该端点，不使用此脚本向生产灌数据。

## 图片与小程序

图片在 `apps/client/src/static/testing/`，编译进入H5及小程序产物。轮播/专题URL默认指向本机H5的 `/static/testing/*.png`。手机中的127.0.0.1是手机自身，真机/远程测试需在后台将图片换成测试站点真实HTTPS地址或受信图片域名。推荐卡片使用同源静态路径。

生产静态包存在图片不代表生产数据库会出现示例资讯，正式运营应使用真实封面。

## 验收

`python scripts/workbench_demo_acceptance.py` 在全新隔离库验证6篇三类资讯、3张专题轮播、专题内容、重复加载无新增、没有伪造发送批次、PNG本地HTTP可读，以及真实H5首页→专题→详情。报告为 `reports/workbench-demo.json`。与固定端口的API、浏览器验收及人工工作台顺序运行，不抢占不明进程。

演示数据不承担生产内容交付或真实平台联调证明。
