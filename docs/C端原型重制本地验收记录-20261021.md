## 原型专项覆盖

版本化场景映射见 `docs/spec/client-prototype-requirements.json`，由本地门禁逐个检查对应 API 与浏览器 case，而非仅依据页面存在。

- 登录取消保留当前页面、同意前不请求登录、同意后继续原意图。
- 首页双列、运营推荐真实排序与去重、后台活动栏目可达；类型 OR 查询，筛选取消不写入。
- 板块/标签生命周期、关键词交集筛选、游标绑定筛选、多类型快照无重复。
- 真实关注关系分组、四项预览、更多列表搜索与取消；批量标签保存的事务回滚、参数校验和匿名拒绝。
- 信息盒子摘要失败/重试不写已读；真实触摸只揭示按钮，显式确认后才写入当前版本。
- 正文与完整原文分离、取消收藏不写入、确认收藏真实持久化、分享链接、真实关键词关系。
- 新增关键词 DAILY 规则、已有对象不重复创建、三视图实际计数、暂停持久化。
- 个人菜单与资料/活动/申报/资源入口；320/375/390/430px 指定页面无横向溢出，页面运行错误为零。

## 验收故障与修复

详细过程见开发日志。期间修复 MySQL DISTINCT 排序、H5 学校选择器层级、登录弹窗页面归属、旧登录页跳转、button 语义及运营入口。原型 touch 测试改用完整 Touch 对象，原文断言按实际 innerText 保留两段精确文本。旧提醒保存不再自跳转同一路由，改为读取服务端列表并清空表单，避免随后操作与重建页面竞争。

完整回归曾在读取个人状态时出现网络失败，记录失败报告后定位并重跑；不删除业务断言，不把未执行的后续场景计入通过。中间失败截图和调试脚本保留在忽略目录，不属于源码交付。
