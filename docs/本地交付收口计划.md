# 本地交付收口计划

2026-10-05 开始，分支 `feature/local-delivery-closure`。C 端始终以 `apps/client` 的 uni-app 为唯一页面与业务源码，编译 H5/微信小程序；管理后台为 `apps/admin` Web 工程。

执行顺序：

1. 内容替换链和用户明确确认转关注；不可见目标和历史不泄露正文；处理环、重复和并发。
2. 真实可视曝光、前后台停留计时、确切版本已读及 409 恢复；抽出两端共用的 uni-app 业务模块。
3. STAFF/CUSTOMER 会话和权限、每个业务写动作的审计、后台按钮、导出与跨角色页面流程。
4. 实际接口类型化和两端模型，逐项决定计划接口映射；核对既定功能全部子操作。
5. 固定依赖更新、构建回归和在线安全扫描；记录供应商未修复风险，不强行接受风险。
6. 从空库重新执行 API/浏览器/运维回环，更新文档、机器门禁和研发交付包，推送私有 GitHub。

无外部资源也可以完成适配设计、协议解析和合成故障测试；真实 AppID、模板用途、企微应用、域名和测试账号仍是实际登录/送达的前提。没有目标 Linux 主机时不宣称 TLS/systemd/恢复时限已经认证。旧数据迁移不在本轮范围。执行结果以新的报告为准，不预写通过。
