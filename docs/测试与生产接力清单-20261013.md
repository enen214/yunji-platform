## 5. 部署团队操作与发布条件

1. 目标已确认 Linux x86_64/amd64，Docker 可用。按部署手册先建隔离试验环境，记录 Git SHA、镜像摘要和配置版本。
2. 按手册配置数据库、Redis、稳定身份密钥、域名/TLS与私有文件卷，执行 V1～V22 迁移。首次空库 bootstrap 设置独立管理员密码；升级不可重复 bootstrap。禁止在目标环境导入本地夹具或使用默认管理员密码。
3. 验证健康检查、前端路由/反向代理、上传下载权限、数据库和文件备份恢复、升级/回退以及日志。数据库迁移只增不改；涉及回退应使用经演练的兼容方案或数据库与文件一致备份。
