## 工程边界

- C 端保持 uni-app + Vue 3 + TypeScript 唯一源代码，编译 H5、微信小程序；管理后台仍为 Web。没有引入 web-view 包装原型，没有复制原型的 DOM 脚本、模拟数据或旧 demo 业务代码。
- 保留公司授权后端基座及依赖、运行配置，数据库仍为 V1～V22。本轮通过现有表与向后兼容接口扩展实现，不要求迁旧数据。
- 适配业务页面内容，不把演示器侧栏、手机边框、假状态栏和假微信胶囊放进产品。小程序首页依据实际状态栏、原生胶囊尺寸避让；其他页面使用原生导航。
- 颜色 #50a770，浅绿色背景、白色圆角卡片、细边框、紧凑字号；首页双列正文卡无封面时不造图。多端均使用编译后字面色值。

## 原型 13 项待确认的工程决定

| 项 | 决定与实现约束 |
| --- | --- |
| 1 原文 | 使用已有 originalText；和 richText、interpretation 分离。展开来源卡显示完整原文，无原文显示“暂无原文”，不以正文冒充。 |
| 2 关注预览 | 每组最多四项，更多进入带组标识的独立列表页；搜索和取消关注直接生效。 |
| 3 折叠 | 管理关注、推送标签默认折叠；返回刷新服务端数据，保留仍挂载页面的展开状态。 |
| 4 取消关注 | 明确文字按钮；写成功才更新状态，失败展示原因，不凭本地数组假称取消。 |
| 5 手机号门槛 | 公开浏览不强制手机号；登录不制造手机号授权。资料页只显示服务端返回的脱敏号或未绑定状态。 |
| 6 微信授权 | 微信 code 使用原生 uni.login；订阅消息沿用平台就绪保护。没有真实平台接线时不展示模拟授权成功、扫码绑定成功或累计额度加一。 |
| 7 网络状态 | 使用 PageState 等组件与现有页面错误状态，包含加载、重试、空态与提交防重；UI 不替代后端幂等和权限。 |
| 8 个人资料入口 | 用户卡进入资料页，列表不重复列“个人信息”。 |
| 9 管理关注入口 | 移到信息盒子顶部；我的页保留强提醒、活动和四个菜单项。报名/申报/服务/资料入口由活动总览继续提供。 |
| 10 时段 | 使用服务端返回的三个可配置时段与时区，不硬编码演示时间。保存携带 expectedVersion。 |
| 11 授权统计 | 展示 available / reserved / consumed；本地合成授权明确标注，不等同真实平台授权。 |
| 12 已知悉 | 确认当前展示的 versionId；409 提醒加载新正文，不能把旧正文的确认记成新版本已读。 |
| 13 数字 | 首页未读/今日已发、板块公开内容数来自接口；不显示没有定义统计口径的“昨日新增12/失效3”。 |

## 页面与实现

| 页面组 | 实现与真实行为 |
| --- | --- |
| 首页 | 搜索、运营轮播、登录用户更新提示、运营推荐按配置顺序进入双列并与检索结果按资讯 ID 去重、分类多选草稿确认、游标加载；保留实际曝光与可见停留统计。 |
| 信息盒子 | 顶部关注/推送标签入口、三 Tab、盒子暂停/恢复/隐藏/取消、资讯摘要按需展开。左滑仅显示按钮，点击才写已读；已有版本冲突处理。 |
| 板块/标签 | 彩色卡片、真实内容计数、目录介绍、子标签、关注；标签页关键词多选 OR，和当前标签取交集，空选择仍限当前标签。 |
| 搜索/关键词 | 实际搜索历史、达到匿名化阈值的热词；类型、板块、学校与组织、标签、过期搜索。关闭筛选丢弃草稿。标签关键词列表合并运营编排和公开内容关系，去重后过滤。 |
| 资讯详情 | 类型/来源/日期/状态、正文/解读、独立原文展开；左侧可收起操作栏，收藏/关注/关键词/分享/提醒各自弹窗，已读与举报保留。 |
| 管理关注 | 关键词/信息两 Tab；根据真实标签关系归组。关键词可由运营编排或公开资讯关系关联到多个标签；多归属允许重复展示，取消一次会从所有组移除。无关系进入未归类组。 |
| 更多关注 | 带 group 与 kind 路由参数；组名来自真实目录；名称搜索、逐项取消、进入实际对象页。 |
| 强提醒 | 日常/即时/关键词三视图，计数含暂停规则，关键词视图和前两者重叠，不能相加。待处理更新单独列出，不能把规则数当作待发消息数。 |
| 新增强提醒 | 可搜索资讯/关键词；添加立即创建 DAILY 跟踪。相同对象已有规则时转编辑，不新建重复规则；不伪造一次待发更新。 |
| 提醒设置/授权/记录 | 时段单选、总开关、企微真实绑定状态；保留乐观锁、真实额度和批次状态。兼容日程提醒保留独立入口，不合并旧账本。 |
| 活动/申报 | 使用现有真实表单版本、名额/候补、材料上传/校验与草稿/提交状态；不把原型提示框当提交成功。 |
| 活动专栏 | 轮播 ARTICLE 链接展示其实际资讯，可继续进入详情；活动/申报/资料为通用入口，活动总览保留后台配置的栏目入口。现有轮播模型没有“一个专栏多篇关联文章”，不猜造关联。若甲方要编辑专题聚合，另增运营模型与验收。 |
| 资料/工具 | 保留真实资料包、插件版本、教程关联、鉴权票据下载，不写死文件数，不添加不存在的文件。 |
| 个人/收藏/历史/反馈/协议 | 用户卡进资料，四项菜单；资料保存/注销/退出、收藏/历史删除及清空均接真接口。协议仍版本发布与同意留痕，about 使用已确认事实文案。 |

## 模块及二次开发

- `apps/client/src/styles/tokens.scss`：跨端编译色值；`prototype.scss`：本轮布局；`app.scss`：存量通用基础。调整控件时检查 H5 默认样式和 MP 编译样式的优先级，不能仅看浏览器。
- `features/auth.ts` + `components/LoginSheet.vue`：内存中的单个登录意图、所属页面栈、取消与异步结果失效。关闭不执行动作；离页放弃意图，过期响应不跳转；没有把 code 或授权密钥写到项目文档。
- `components/CatalogDetail.vue`：板块/标签共用组件，页面根传入 id 并转接 onShow/onReachBottom，避免在普通组件中误用页面生命周期。
- `features/follows.ts`：真实归属分组；接口 FollowView.labels 提供 id/name/categoryId/categoryName，不从标题文本猜归属。更多关注页使用同一分组函数。
- `components/PageState.vue`：可复用加载/错误/空态；重试仅重新读取，不应擅自重复提交不可逆业务。
- `api/platform.ts`：私有页面门槛与 authenticated(action)，原有请求幂等键、网络重试和 401 失效保留。表单提交不应无提示自动重放；简单关注、收藏可以由当前明确意图继续。

## 接口扩展与兼容性

1. GET /api/v1/articles/search：contentType 可逗号分隔多种枚举，最多六种；新增 keywordIds（最多30个正数），关键词之间 OR，与标签、学校、板块条件 AND。原 keywordId 单值继续兼容，若同时传两者则分别形成 AND 条件。游标绑定整个筛选条件，不能跨筛选重用。
2. GET /api/v1/articles/{id}：新增 labels / keywords（已启用、同租户目录关系），ID 为字符串。只有当前可公开阅读的资讯才能读取关系；不返回草稿关系快照。
3. GET /api/v1/me/follows：新增 labels。关键词归属来自有效运营编排或可见资讯的标签关系，不构造唯一假父标签。
4. PUT /api/v1/me/follows/labels：批量保存1～100个标签关注，去重排序，单个事务内全部成功或全部回滚；匿名和工作人员 token 不可代用户操作。
5. GET /api/v1/me/reminders/rules：新增 targetType / targetId 条件；返回当前用户过滤后的真实 total。指定 targetId 必须同时指定 type，防止同数字不同对象混淆。
6. POST /api/v1/me/feedback：新增可选类型和选填联系方式，旧调用兼容。联系方式作为明确标注的未验证用户文本写入工单描述，不存成已验证身份。
7. GET /api/v1/home：运营推荐卡新增 contentType/sourceName/publishedAt，来自关联的实际公开资讯；保持原有 articleId、标题、摘要等字段，前端不再为每个推荐补查详情。首页先按运营配置排列，再拼接去重后的搜索结果；活动总览继续展示 activityColumns 的真实板块入口。

H5 业务底部弹窗高于 tabbar；框架 picker/modal/toast 另设更高层级，确保学校选择和系统确认可点击。该覆盖仅在 H5 编译，小程序使用原生控件。button 组件显式提供 role，原生分享继续使用 open-type，不通过 DOM 模拟微信操作。

## 已保留的容量边界

本轮没有把全工程所有列表改为无限规模接口。关注/收藏/历史沿用最近200项的现有上限，盒子每组最多100条；管理关注达到200项时给出提示，页面计数只针对返回集合。关键词目录也受原服务端查询上限约束。若接收方需要大规模全量检索，应先定义分页/全量计数契约与容量指标，不能只在前端删除提示。
