## 1. C 端用户操作

### 1.1 首页和筛选

打开 H5 的 `/#/`，或在微信开发者工具打开同一份 uni-app 构建产物。左上角品牌为“云迹”，顶栏是资讯板块入口；下方的学校/组织选择器是第二筛选维度，页面不再另放一个重复的“全部分类”入口。

首页首次加载没有搜索、板块或组织筛选时，服务端按热点条件展示 `hot_weight > 0` 的资讯。新建草稿的热点值默认为 0，所以刚创建但尚未设置热点的资讯可能不会出现在首页；选择板块、学校/组织或执行搜索后，热点限定关闭。排序综合考虑关注提升、置顶、重要度、热点、新鲜度、活动临近程度，再以发布时间和 ID 稳定排序。

搜索时输入关键词并提交；可以叠加板块和学校/组织条件。过期资讯可以从搜索、收藏或历史进入，但撤回后被替换的旧正文不再公开展示，只保留替换关系、历史记录和审计证据。

### 1.2 详情和登录

2026-10-22：微信小程序登录提供“手机号一键登录”和“普通微信登录（不授权手机号）”。先同意协议；手机号授权由微信弹窗确认。拒绝不会登录或自动扣取手机号额度，可主动选择普通登录。H5 仍用本地工作台合成码测试，不能模拟微信原生手机号授权。

详情页按顺序展示摘要、干货正文、解读、原始信息、来源和有效期。文件或长图属于载体分类，下载仍受主体绑定和一次性票据控制。

本地 H5 开发模式：

1. 在仓库根目录执行 `python scripts/workbench.py start`。
2. 另一终端执行 `python scripts/workbench.py code alice`，复制短时单次码。
3. 登录页的“本地验收登录”中粘贴登录码，点“登录合成用户”；页面内置 `local-client`，无需另选 AppID。

微信小程序使用 `uni.login`，需要真实 AppID、HTTPS 合法 API 域名和服务器端 AppSecret。生产 H5 没有无平台资源的客户登录方式；不要把本地合成码当作正式登录。

### 1.3 收藏、关注和信息盒子

- 详情页可关注单条资讯或收藏；取消操作可重复，结果以服务端当前状态为准。
- “我的订阅”包含“板块推送”“关注更新”“更替推送”三个盒子。
- 在“关注更新”内“查找”关键词后点“订阅”即可关注关键词；在“板块推送”的“允许推送的板块”中订阅板块。
- 普通盒子可以“暂停盒子推送/恢复盒子推送”或“隐藏盒子”；点“显示隐藏盒子”后对目标盒子点“取消隐藏”。取消隐藏不会删除关注；更替盒子只展示迁移通知和新资讯入口。
- 单条资讯和关键词盒子可以“设置提醒”；发送前仍受额度、授权和外部平台状态控制，板块盒子没有这一按钮。
- 管理端确认资讯更替后，原资讯下线，单条关注和强提醒自动迁移到新资讯；用户在更替提示中选择“查看新资讯”。历史和审计保留，授权额度不增加。

### 1.4 活动、资料和个人页

“资料与工具”进入资料包和文件；“正在开放的活动”进入活动详情、报名和候补；“学生申报”进入申报表单和材料状态。“我的”包含收藏、历史、报名、申报、反馈、退出登录和账号关闭入口。报名、申报和文件操作出现 401/403/409 时，先刷新当前页面，不要连续创建新提交。

### 1.5 本地 C 端验收路径

至少检查：

1. 顶栏板块切换、学校/组织筛选、搜索和热点首页规则。
2. 详情内容、来源跳转、收藏、单条关注和历史。
3. 三个信息盒子、暂停/恢复、隐藏/显示、更替提示和提醒设置。
4. 活动报名、资料下载、反馈、退出登录和受保护页面重定向。
5. 断开或刷新后重复提交：同一动作不产生重复关系；409 后重新读取服务器版本。

## 2. 管理后台操作

入口为 `/admin/#/login`。正式部署使用 `bootstrap` 后的管理员账号；本地隔离工作台可用 `admin/admin123`、`test1/666666`、`test/666666`，它们只用于本地夹具。

### 2.1 资讯编辑和版本

进入“资讯与审核”，点击“新建资讯”。字段规则：

| 字段 | 规则 |
| --- | --- |
| 标题 | 最多 255 字符 |
| 一句话摘要 | 最多 1000 字符 |
| 正文 | 基础 HTML，服务端清理危险标签和属性 |
| 解读 | 最多 30000 字符 |
| 原始信息 | 最多 100000 字符 |
| 板块 | 必选且只能选一个 |
| 学校/组织、关键词 | 可多选，独立于板块 |
| 内容类型 | `BASIC`、`ACTIVITY`、`REVIEW`、`GUIDE`、`RESOURCE` |
| 载体 | `TEXT_IMAGE`、`LONG_IMAGE`、`FILE`，只表示载体分类 |
| 生效时间/失效时间 | 使用页面本地时间，提交时转换为 UTC |
| 置顶 | 勾选后进入排序权重 |
| 重要度/热点/新鲜度 | 分别为 0–5、0–10、0–5 |
| 变更摘要 | 创建修订时最多 500 字符 |

先点“保存草稿”。修改已发布内容必须点“创建修订”，不能直接改公开版本。审查和发布绑定版本与锁版本，发生 409 时重新打开当前版本再处理。

### 2.2 审核、发布、下线和更替

推荐流程：

1. 创作者“提交审核”。
2. 审核员检查来源、有效期、板块、组织、正文和载体，选择“通过”或“退回”；退回必须填写原因。
3. 有发布权限的工作人员点击“发布此版本”。
4. 需要提前结束时点击“下线”；不要删除已公开版本来伪造历史。
5. 内容修订用“创建修订”。
6. 内容被替换时点击“替换资讯”，选择“替换目标”，确认后旧资讯下线，新资讯成为公开目标，关注和强提醒按服务端规则迁移。

发布前必须确认来源 URL、责任组织和有效期。单条资讯只能有一个板块，学校/组织和关键词不代替板块；同一页面不使用重复分类入口。

### 2.3 目录、组织和关键词

“分类目录”维护板块，“学校与组织”维护学校/学院/部门，“关键词治理”维护搜索和订阅用词。

1. 点“新建”，填名称和稳定编码，选择父级、状态和排序后点“保存”。稳定编码用于长期识别，不随文案调整反复重建。
2. 学校选 `SCHOOL`，学院选 `COLLEGE`，部门选 `DEPARTMENT`；上级组织用于表达真实归属，不把学校标签写死在 C 端。
3. 在关键词行点“别名”新增等价叫法；点“禁用”填写理由，避免继续暴露不应订阅的词。
4. 用“编辑”更正状态和顺序；“撤下”有引用时可能被拒绝，先核对现有资讯、订阅和统计关系。
5. 保存后回到 C 端刷新目录和筛选，确认学校/组织是顶栏板块之外的独立维度。

删除或停用失败时保留服务端错误和审计记录，不直接改数据库。

### 2.4 活动、评审和资料

**“活动与报名”**：点“新建”，填写标题、学校/组织、可选关联资讯、报名开始/截止、活动开始/结束、名额和“启用候补”。点“添加字段”定义报名字段的标识、显示名、必填、类型（`TEXT`、`NUMBER`、`CHOICE`）、最大长度；选择题填写逗号分隔选项。先保存 `DRAFT`，核对表单后用“编辑”调整为 `PUBLISHED`；停止报名用 `CLOSED`。点“查看”核对参与者、报名状态、提交时间和答案；有导出权限时点“导出参与者名单”。并发满额以服务端结果为准，不手改名额计数。

**“评审项目”**：点“新建”，填标题、学校/组织、可选关联资讯和开放/截止申报时间。用“添加字段”定义材料标识、名称、必填、允许文件类型、最大字节数和资格所属组织。当前材料允许 PDF、PNG、JPEG、文本，最大上限由服务端及配置共同决定，页面最高值 10485760 字节。先保存草稿，确认要求后发布；已有提交的项目调整须保留历史版本。

**“材料评审”**：点“查看”再点“查看材料”，核对确切提交版本。选择 `APPROVED`（通过）、`REJECTED`（拒绝）或 `CORRECTION`（补正），填写意见，点“提交评审决定”。意见最多 1000 字符。决定绑定当前提交与锁版本，出现 409 后刷新并重新核查，不能把旧材料的决定强套到新提交上。

**“文件治理”与“资料包”**：先在“文件治理”上传允许类型的文件（页面选择 PDF、PNG、JPEG、TXT、ZIP，服务端进一步校验类型、大小和归属），再在“科目”维护组织内唯一科目代码，最后新建资料包，填写标题、学校/组织、科目、类型（`TEXTBOOK`、`REVISION`、`GENERAL`）、可选关联资讯和文件。资料包先存草稿再发布；下载通过主体绑定的一次性票据，不把附件目录配置为 Nginx 静态目录。引用中的文件不能直接撤下。

**“考试日程”“年级与专业”“插件发布”**：考试需填写组织、科目、时间、显示时区和来源；年级/专业使用稳定字典编码。插件先创建名称、平台和使用教程，再“查看”该插件，填版本号、发布包和发布说明，点“发布版本”；已冻结版本保留 SHA256，更新使用新版本。自动 OCR、长图文字识别和版式提取不在本期能力范围。

### 2.5 用户、提醒、反馈和分析

“系统管理”维护工作人员、角色、部门和菜单权限；“内容效果”查看客户账户数量等聚合，不提供一个通用的客户账号管理页。权限调整遵循已批准角色矩阵。“提醒账本”查看额度预占、重试和 `UNKNOWN` 冻结；没有真实微信/企微资源时保持发送拒绝，不绕过供应商保护。

反馈、举报和审计页面记录处理人、时间、状态和决定。统计页面可查看内容曝光、停留和聚合结果；H5 已有本地回环证据，微信小程序真机采集仍待平台验收。不要把统计结果解释成推荐系统；I3 相关推荐、I4 词条解释和 H3 关联仍是未开发范围。

具体操作：

- “内容举报”“用户反馈”的待处理记录可“解决”或“驳回”；处理结果要与核实事实一致，不能用关闭工单隐藏实际问题。
- “内容效果”可选 UTC 自然日后点“重新生成日报”。“导出当前列表”仅对有 `yunji:export` 权限的人员显示；导出提示截断时按限定行数分批处理。
- “操作审计”只读查看主体、对象、动作和时间；有授权时导出，不在数据库中删除证据。
- “提醒账本”的“执行提醒任务”在本地演练环境只推进合成账本。`UNKNOWN` 只能在取得供应商回执后点“核实已送达”或“核实永久失败”，并填写回执编号、核实时间和结论（至少 10 字符）；资源缺失时不要编造回执。

### 2.6 系统管理与运营页面

进入“系统管理”，先维护部门和普通角色，再“新建工作人员”：填写账号、姓名、16–20 字符初始口令、所属部门和工作人员角色，保存后安全交接临时口令。在目标用户行点“业务授权”，设置资讯部门范围和评审组织范围，再点“保存业务授权”；菜单权限与业务范围都需要配置，只有页面可见不代表拥有业务数据范围。“重置口令”会影响会话，调整后用目标角色重新登录复核。

“首页轮播”需填图片地址、目标类型、目标值、生效窗口和顺序；目标必须存在且可见。“首页推荐位”是人工选位，不等于 I3 算法相关推荐。“活动栏目”关联目录。“协议与关于”按 `terms`、`privacy`、`about` 页面标识发布正文，新正文形成新版本，既有同意记录保留旧版本。后台保存成功后，还要在所交付 C 端页面核对实际展示；配置接口存在不自动证明每个运营位都有前端呈现。

## 3. 角色与常见错误

| 角色 | 典型操作 | 不应拥有 |
| --- | --- | --- |
| 创作者 | 新建草稿、创建修订、提交审核 | 审核、发布、跨组织读取 |
| 审核员 | 查看授权范围、通过/退回、处理评审 | 直接修改已发布正文、越权发布 |
| 发布/运营人员 | 发布、下线、更替、维护目录和运营配置 | 修改审计、绕过状态机 |
| 管理员 | 用户、角色、系统配置和全部受控运营操作 | 以数据库手工改写替代审计 |
| C 端客户 | 浏览、收藏、关注、报名、反馈和自己的文件 | 访问他人数据或工作人员接口 |

- **401**：会话过期或未登录，重新登录并重做当前读取。
- **403**：角色、组织范围或资源归属不足，联系管理员调整批准的权限。
- **404**：对象不存在或对当前主体不可见，不用猜 ID 重试。
- **409**：版本、状态或幂等冲突，重新读取当前对象；原请求若结果未知，复用原 `Idempotency-Key`。
- **422**：字段约束错误，按页面提示修正。
- **503**：外部平台或通知供应商不可用；保持平台待接入状态，不开启本地网关。

## 2026-10-21 C 端现行界面教程

- 首页从搜索框进入搜索，学校/组织与板块筛选统一在搜索的“筛选”弹层。首页“全部”按钮只筛选资讯类型，支持多选；点确定才生效，取消保留原结果。普通公开内容不要求登录。
- 我的页用户卡进入个人资料；服务区为强提醒和活动，下面为管理收藏、浏览历史、平台反馈、关于我们。我的报名、我的申报和全部服务在活动总览中继续可达。
- 点需要身份的菜单，先出现可关闭的登录底部弹窗。需勾选协议后登录；关闭/暂不登录不执行原操作，成功才继续当前意图。本地验收码只供工作台使用，真实版使用微信原生登录。
- 资讯详情左侧小把手展开操作栏，分别进入收藏、关注信息、关键词、分享与强提醒弹窗。收藏/关注需确认；关键词来自这条资讯的真实关系。原文在“查看原始来源”内展开，没有原文不会显示正文充数。
- 信息盒子中“展开摘要”仅阅读摘要；点击标题看全文。左滑只显示确认按钮，必须点“标记已读”才确认展示版本。版本已变化时按提示加载新正文，不要重复点击旧版本确认。
- 管理关注默认折叠；关键词与信息两 Tab 按真实标签归组，每组最多四项预览。“更多”打开完整返回集合并可搜索、取消关注；多标签对象可能出现于多个组，取消一次会从各组消失。
- 选择推送标签可展开板块，逐项选择或一键保存标签组；关注整个板块与全选标签是不同操作，界面分别标明。
- 新增强提醒选择资讯或关键词并点添加，成功后即保存 DAILY 规则，不需再点保存；已有规则转编辑。日常/即时按规则模式展示，关键词页是关键词规则的另一视图，三个计数不能相加。
- 设置页的三个时段来自后台，点选后点保存；取消不写入。企微未绑定不能伪造扫码成功。即时规则仍受真实一次性授权限制，本地模拟状态在通道页标明。
- 平台反馈选择类别，填写问题和可选联系方式；联系方式只是用户填写的工单文本，不代表已验证手机号。
