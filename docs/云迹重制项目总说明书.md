## 1. 项目定位

云迹是面向大学生的信息服务平台。它把筛选后的资讯、解读、来源、时效和关注关系组织成可审核、可追溯、可发布的内容系统，并为客户提供 H5/微信小程序 C 端，为工作人员提供管理后台。

本工程从公司 `cis4j` 首次框架基座重新设计业务，不复用 `yangben` demo 的业务代码、旧表结构、旧接口或旧部署脚本。`yangben` 只作为研究线索和来源核查对象；来源核查报告要求非基座完整/去空白代码匹配为 0。

## 3. 系统组成

```text
微信小程序 / H5 C 端（apps/client，uni-app 同源） ─┐
                                                  ├─ HTTPS / Nginx ─ Spring Boot API
管理后台（apps/admin，Vue 3 + TypeScript） ────────┘                 │
                                                                    ├── MySQL 8：业务数据、版本、审计、通知账本
                                                                    ├── Redis 7：会话、并发和运行时协调
                                                                    └── 私有附件目录：主体绑定、短时单次票据
```

后端业务模块按领域划分：identity、catalog、article、subscription、engagement、activity、review、resource、notification、analytics、operation 和 shared。C 端和管理端是两个独立客户端，都通过 API 访问业务；真实微信/企微是尚未接入的外部平台。API 契约以 `contracts/openapi.json`、`contracts/openapi.yaml` 为准。

## 4. 需求实现边界

### 已纳入基线

- 内容库：标题、一句话摘要、干货正文、解读、原始信息、来源名称和来源跳转。
- 分类：资讯只能属于一个板块；关键词、学校/组织和载体是独立维度。
- 生命周期：待生效、生效、失效；失效进入历史库，不进入当前推送。
- 属性与排序：重要度、热点、置顶、新鲜度、关注优先和重复曝光限制。实现排序为关注提升 50、置顶 100、内容权重、热点权重、新鲜度权重×2，以及活动临近加分 `max(0,20-floor(hoursUntilStart/12))`，最后按发布时间和 ID 稳定排序。
- 信息盒子：板块推送、关注更新、更替推送三栏。
- 订阅：板块、关键词、单条资讯关注；盒子推送可单独暂停或恢复。
- 内容更替：管理端确认更替；旧资讯下线；关注、强提醒自动迁移；历史和审计保留。
- 活动、报名、攻略、资料包、评审、反馈、举报、统计和附件生命周期。

### 明确边界

- H3 信息关联、I3 相关推荐、I4 专有词浮动解释：需求清单标记未开发。
- B3 长图/文件自动提取：只完成载体分类和文件关系，OCR/版式提取待单独定义。
- I2 活动最终展示形态：活动领域和报名闭环已具备，具体运营频道由接收团队确认。
- F2 企业微信、F3 微信订阅消息、AUTH-02 真实微信身份：本地只验证账本/合成路径，生产发送保持关闭直到平台资源和送达证据齐全。
- AUTH-05、CAT-06：候选需求，不计入 79 项基线。

## 5. 数据与安全模型

MySQL 使用 UTC 和 `utf8mb4`。资讯版本不可变，发布指针只能通过显式状态转换更新。已实现并回环的业务写操作按主体、角色、组织范围、状态、幂等键和乐观锁校验，并写入审计；这句话不替代对框架所有接口的无限承诺。工作人员和客户使用分离身份与 token，不能互换。

首页无搜索和筛选时默认 `hotOnly=true`，只展示 `hot_weight > 0`；板块、组织或搜索条件会关闭该限定。登录客户对无搜索列表的曝光按 UTC 日期至少 3 次、服务端 30 秒计数冷却控制，匿名请求不做个性化。可见曝光和停留本地 H5 已验收，小程序真机仍待平台验收。

迁移从 `framework-schema.sql` 后按 V1–V22 顺序执行，迁移文件记录 SHA256，已应用文件被改写会拒绝继续。生产使用独立迁移账号和应用账号；稳定保存身份 HMAC、身份加密密钥和 token secret。私有附件只能通过主体绑定、短时、单次票据访问，Nginx 不直接暴露附件目录。

## 6. 前端使用原则

C 端只有一套 uni-app 源码，同时构建 H5 和微信小程序。首页顶部“云迹”是品牌标识；顶栏负责板块筛选，下方只保留学校/组织筛选，避免同一分类出现两个入口。管理端服务内容审核、目录、权限、文件、活动、评审、通知账本和统计。
